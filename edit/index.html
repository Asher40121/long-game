How this works and what's stored

Long Game is a portfolio demo. Every company, founder and number is fictional. It isn't affiliated with any real company.

Stored only in your browser: the demo data and any changes you make (touchpoints, ratings, weights) are saved in this browser's local storage. There are no accounts, no analytics and no server. Nothing you type is sent anywhere.

Scores are calculated, not guessed: fit is a transparent weighted tally and relationship health compares days since the last touch with the cadence each stage calls for.

AI: decision briefs in this demo are pre-written sample outputs, labeled as such. No AI calls are made and nothing costs money.

Reset demo data?

This removes your changes (touchpoints, ratings, weights and any targets you added) and restores the original fictional data.
